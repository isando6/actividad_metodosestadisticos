Análisis exploratorio con variable respuesta numérica: prueba con el conjunto de datos ‘California Housing’

Karina Núñez Sarmiento, Isabella Sandoval Escorcia

2026-08-21

1 Introducción

1.1 Contexto del problema

El conjunto de datos utilizado en este trabajo, housing.csv, corresponde al conjunto de datos conocido como “California Housing”. Fue originalmente compilado por Pace y Barry (1997) a partir del censo de Estados Unidos de 1990, y el archivo específico utilizado en este trabajo fue obtenido a través del repositorio de Scikit-Learn. Cada observación representa un bloque censal (block group), definido por la Oficina del Censo de Estados Unidos como la unidad geográfica más pequeña para la cual se publican datos muestrales, agrupando típicamente entre 600 y 3.000 personas (U.S. Census Bureau, s.f.). En total, el conjunto contiene 20.640 observaciones y 10 variables.

Este conjunto de datos es ampliamente utilizado en el ámbito académico y de aprendizaje automático como caso introductorio para problemas de regresión (Géron, 2022), dado que combina variables numéricas, una variable categórica y una variable objetivo continua (el valor medio de las viviendas), lo cual permite ilustrar de forma práctica técnicas de análisis exploratorio, preprocesamiento de datos e ingeniería de características.

El objetivo general que motiva el análisis de este conjunto de datos es comprender qué factores (siendo estos geográficos, demográficos, habitacionales y socioeconómicos) se relacionan con el valor medio de las viviendas en los distintos bloques censales de California, así como en qué medida dichos factores podrían utilizarse para predecir el valor evaluado en cuestión.

1.2 Variables del conjunto de datos

El conjunto de datos incluye las siguientes variables:

  • longitude: longitud geográfica del bloque censal (grados).

  • latitude: latitud geográfica del bloque censal (grados).

  • housing_median_age: antigüedad mediana de las viviendas del bloque censal (años).

  • total_rooms: número total de habitaciones en el bloque censal.

  • total_bedrooms: número total de dormitorios en el bloque censal.

  • population: número total de personas que residen en el bloque censal.

  • households: número total de hogares (unidades habitacionales ocupadas) en el bloque censal.

  • median_income: ingreso mediano de los hogares del bloque censal, expresado en decenas de miles de dólares estadounidenses.

  • median_house_value: valor mediano de las viviendas del bloque censal, expresado en dólares estadounidenses. Esta es la variable objetivo (target) del análisis.

  • ocean_proximity: variable categórica que indica la cercanía del bloque censal al océano, con las categorías: <1H OCEAN (a menos de una hora del océano), INLAND (interior, alejado de la costa), NEAR OCEAN (cerca del océano), NEAR BAY (cerca de una bahía) e ISLAND (ubicado en una isla).

Cabe destacar que, dado que los datos provienen del censo de 1990, los valores absolutos de median_house_value y median_income no reflejan los precios de vivienda ni los niveles de ingreso actuales. Empero, esto no afecta el análisis de las relaciones y patrones entre las variables, que es el objetivo central de este trabajo.
